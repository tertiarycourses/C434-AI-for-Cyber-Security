## About the course

This course develops defensible ways to use AI in cyber defence. Learners distinguish evidence from inference, design measurable AI security programmes, establish architecture and automation boundaries, and monitor operational effectiveness against standards. All practical work uses synthetic data, controlled browser simulations and explicit human-oversight controls.

## Learning outcomes

By the end of the course, learners will be able to:

- identify security risks, threats, vulnerabilities and control gaps using AI-assisted analysis;
- translate security objectives and evidenced gaps into measurable cybersecurity programmes;
- develop architecture-aligned action plans with ownership, validation and rollback;
- advise on adoption and monitor AI security solutions against standards and operational evidence.

## Topics covered

1. AI-assisted security risk, threat and control-gap analysis
2. Designing AI-powered cybersecurity programmes
3. Developing AI-driven security architecture and action plans
4. Monitoring, evaluating and governing AI security solutions

Day 1 covers Topics 1–2 and Labs 1–7; Day 2 covers Topics 3–4 and Labs 8–12.
