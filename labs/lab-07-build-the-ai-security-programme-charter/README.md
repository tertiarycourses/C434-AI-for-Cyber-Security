# Lab 07 - Build the AI Security Programme Charter

Start with [lab-guide.md](lab-guide.md), then use [tool-exercise.md](tool-exercise.md) for the controlled simulator practice.

- `data/`: primary synthetic input
- `mock-data/`: three or more fictional supporting datasets
- `tool-exercise.md`: authorised simulator/Kali-style practice and offline fallback
- `starter/`: learner implementation
- `solution/`: reference implementation
- `tests/`: solution and folder-structure checks
- `evidence/`: generated outputs

Training surface: [FauxBank Cybersecurity Training Simulation](https://pentest-fauxbank.vercel.app/).
